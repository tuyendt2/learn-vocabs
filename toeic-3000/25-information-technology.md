### application
- **IPA:** /ˌæplɪˈkeɪʃn/
- **Meaning 1 (n):** A program designed to do a particular job for the user.
  - *Example:* The finance team uses a single **application** for all invoicing.
- **Meaning 2 (n):** A formal request, for a job, place, or permission.
  - *Example:* Her **application** for the grant was successful.

### platform
- **IPA:** /ˈplætfɔːm/
- **Meaning 1 (n):** The hardware or software environment on which programs run.
  - *Example:* The app runs on both mobile **platforms**.
- **Meaning 2 (n):** A service that connects groups of users, such as a marketplace or social network.
  - *Example:* The company sells through its own online **platform**.

### operating system
- **IPA:** /ˈɒpəreɪtɪŋ ˌsɪstəm/
- **Meaning 1 (n):** The core software that manages a computer's hardware and other programs.
  - *Example:* An **operating system** update fixed the battery problem.

### kernel
- **IPA:** /ˈkɜːnl/
- **Meaning 1 (n):** The central part of an operating system that controls the hardware.
  - *Example:* The crash was traced to a fault in the **kernel**.

### driver
- **IPA:** /ˈdraɪvə/
- **Meaning 1 (n):** A small program that lets the operating system communicate with a device.
  - *Example:* Installing the right printer **driver** solved the issue.

### firmware
- **IPA:** /ˈfɜːmweə/
- **Meaning 1 (n):** Software stored permanently in a device to control how it works.
  - *Example:* A **firmware** update improved the router's range.

### middleware
- **IPA:** /ˈmɪdlweə/
- **Meaning 1 (n):** Software that connects different applications or services so they can work together.
  - *Example:* **Middleware** passes orders from the website to the warehouse system.

### code library
- **IPA:** /ˈkəʊd ˌlaɪbrəri/
- **Meaning 1 (n):** A collection of ready-made code that programs can reuse.
  - *Example:* They used an open-source **code library** to handle the charts.

### repository
- **IPA:** /rɪˈpɒzətri/
- **Meaning 1 (n):** A central place where code and its history are stored.
  - *Example:* All the project's files live in one **repository**.

### source code
- **IPA:** /ˈsɔːs kəʊd/
- **Meaning 1 (n):** The human-readable instructions that make up a program.
  - *Example:* The company keeps its **source code** private.

### compile
- **IPA:** /kəmˈpaɪl/
- **Meaning 1 (v):** To convert source code into a form the computer can run.
  - *Example:* The build failed because the code would not **compile**.

### deploy
- **IPA:** /dɪˈplɔɪ/
- **Meaning 1 (v):** To move software into use on a live system.
  - *Example:* The fix was **deployed** to all servers overnight.

### deployment
- **IPA:** /dɪˈplɔɪmənt/
- **Meaning 1 (n):** The act of putting software into live operation.
  - *Example:* The **deployment** is scheduled for a quiet period on Sunday.

### build
- **IPA:** /bɪld/
- **Meaning 1 (n):** A particular compiled version of a program.
  - *Example:* Testers are on the latest nightly **build**.

### release
- **IPA:** /rɪˈliːs/
- **Meaning 1 (n):** A version of software made available to users.
  - *Example:* The next **release** adds two-factor login.
- **Meaning 2 (v):** To make something available to the public.
  - *Example:* They **released** the update a week early.

### version control
- **IPA:** /ˈvɜːʃn kənˌtrəʊl/
- **Meaning 1 (n):** A system for tracking and managing changes to code over time.
  - *Example:* **Version control** let them undo the change that broke the site.

### rollback
- **IPA:** /ˈrəʊlbæk/
- **Meaning 1 (n):** A return to a previous version after a change causes problems.
  - *Example:* The team did a quick **rollback** when errors spiked.

### hotfix
- **IPA:** /ˈhɒtfɪks/
- **Meaning 1 (n):** A small, urgent update released to fix a serious problem.
  - *Example:* A **hotfix** was pushed out within hours of the outage.

### bug tracker
- **IPA:** /ˈbʌɡ ˌtrækə/
- **Meaning 1 (n):** A system for recording and following software faults until they are fixed.
  - *Example:* Every reported fault gets an entry in the **bug tracker**.

### debugging
- **IPA:** /ˌdiːˈbʌɡɪŋ/
- **Meaning 1 (n):** The process of finding and removing errors in software.
  - *Example:* **Debugging** the payment flow took most of the week.

### latency
- **IPA:** /ˈleɪtənsi/
- **Meaning 1 (n):** The delay between a request and the response in a system.
  - *Example:* High **latency** made the app feel slow for overseas users.

### load balancing
- **IPA:** /ˈləʊd ˌbælənsɪŋ/
- **Meaning 1 (n):** The spreading of work across several servers so none is overloaded.
  - *Example:* **Load balancing** kept the site up during the traffic spike.

### redundancy
- **IPA:** /rɪˈdʌndənsi/
- **Meaning 1 (n):** Extra equipment or systems kept ready so that a failure does not stop service.
  - *Example:* Built-in **redundancy** means a single disk failure changes nothing.

### failover
- **IPA:** /ˈfeɪləʊvə/
- **Meaning 1 (n):** The automatic switch to a backup system when the main one fails.
  - *Example:* **Failover** to the second data centre took eight seconds.

### scalability
- **IPA:** /ˌskeɪləˈbɪləti/
- **Meaning 1 (n):** The ability of a system to handle a growing amount of work.
  - *Example:* The rebuild was all about **scalability** for the holiday rush.

### virtualization
- **IPA:** /ˌvɜːtʃuəlaɪˈzeɪʃn/
- **Meaning 1 (n):** Running several simulated computers on one physical machine.
  - *Example:* **Virtualization** let them replace 40 servers with four.

### cluster
- **IPA:** /ˈklʌstə/
- **Meaning 1 (n):** A group of computers working together as a single system.
  - *Example:* The database runs on a three-node **cluster**.

### node
- **IPA:** /nəʊd/
- **Meaning 1 (n):** A single machine or point within a network or cluster.
  - *Example:* One **node** went offline but the others carried the load.

### endpoint
- **IPA:** /ˈendpɔɪnt/
- **Meaning 1 (n):** A device or address at the end of a network connection, or a specific address in an API.
  - *Example:* Each **endpoint** on the network must run the security agent.

### protocol
- **IPA:** /ˈprəʊtəkɒl/
- **Meaning 1 (n):** A set of rules that governs how data is exchanged between systems.
  - *Example:* The devices communicate using a standard **protocol**.

### API
- **IPA:** /ˌeɪ piː ˈaɪ/
- **Meaning 1 (n):** A defined way for one program to request data or services from another.
  - *Example:* The shop connects to the courier through its **API**.

### integration
- **IPA:** /ˌɪntɪˈɡreɪʃn/
- **Meaning 1 (n):** The connecting of separate systems so they work as one.
  - *Example:* **Integration** between sales and stock removed a lot of manual work.

### authentication
- **IPA:** /ɔːˌθentɪˈkeɪʃn/
- **Meaning 1 (n):** The process of confirming that a user is who they claim to be.
  - *Example:* **Authentication** now requires a code from the user's phone.

### authorization
- **IPA:** /ˌɔːθəraɪˈzeɪʃn/
- **Meaning 1 (n):** The process of deciding what an authenticated user is allowed to do.
  - *Example:* **Authorization** rules stop junior staff from deleting records.

### single sign-on
- **IPA:** /ˌsɪŋɡl ˈsaɪn ɒn/
- **Meaning 1 (n):** A system letting a user log in once to access many applications.
  - *Example:* **Single sign-on** cut password-reset requests to the help desk.

### encryption key
- **IPA:** /ɪnˈkrɪpʃn kiː/
- **Meaning 1 (n):** A piece of information used to lock or unlock encrypted data.
  - *Example:* If the **encryption key** is lost, the backup cannot be read.

### hashing
- **IPA:** /ˈhæʃɪŋ/
- **Meaning 1 (n):** Converting data into a fixed-length code, often used to store passwords safely.
  - *Example:* Passwords are kept only as a **hashing** result, never as plain text.

### vulnerability
- **IPA:** /ˌvʌlnərəˈbɪləti/
- **Meaning 1 (n):** A weakness in a system that an attacker could use.
  - *Example:* A researcher reported a **vulnerability** in the login page.

### exploit
- **IPA:** /ˈeksplɔɪt/ (n) · /ɪkˈsplɔɪt/ (v)
- **Meaning 1 (n):** A piece of code or method that takes advantage of a vulnerability.
  - *Example:* An **exploit** for the flaw appeared online within days.
- **Meaning 2 (v):** To use a weakness or resource for advantage.
  - *Example:* Attackers **exploited** an unpatched server.

### ransomware
- **IPA:** /ˈrænsəmweə/
- **Meaning 1 (n):** Malicious software that locks data until a payment is made.
  - *Example:* A **ransomware** attack froze the hospital's records for two days.

### phishing
- **IPA:** /ˈfɪʃɪŋ/
- **Meaning 1 (n):** Sending fake messages to trick people into revealing passwords or bank details.
  - *Example:* Staff training reduced clicks on **phishing** emails.

### spyware
- **IPA:** /ˈspaɪweə/
- **Meaning 1 (n):** Software that secretly collects information from a device.
  - *Example:* The **spyware** was recording every keystroke.

### antivirus
- **IPA:** /ˌæntiˈvaɪrəs/
- **Meaning 1 (n):** Software that detects and removes malicious programs.
  - *Example:* The **antivirus** quarantined the infected file automatically.

### sandbox
- **IPA:** /ˈsændbɒks/
- **Meaning 1 (n):** An isolated area where code can run without affecting the rest of the system.
  - *Example:* Suspicious attachments are opened in a **sandbox** first.

### firewall rule
- **IPA:** /ˈfaɪəwɔːl ruːl/
- **Meaning 1 (n):** A setting that decides which network traffic is allowed or blocked.
  - *Example:* A new **firewall rule** blocked the country the attacks came from.

### proxy
- **IPA:** /ˈprɒksi/
- **Meaning 1 (n):** A server that sits between users and the internet, passing on their requests.
  - *Example:* All web traffic goes through the company **proxy**.

### VPN
- **IPA:** /ˌviː piː ˈen/
- **Meaning 1 (n):** A virtual private network: an encrypted connection over the internet.
  - *Example:* Remote staff connect to the office network through a **VPN**.

### bandwidth cap
- **IPA:** /ˈbændwɪdθ kæp/
- **Meaning 1 (n):** A limit on the amount of data that can be transferred in a period.
  - *Example:* The hosting plan has a monthly **bandwidth cap**.

### cache
- **IPA:** /kæʃ/
- **Meaning 1 (n):** A store of data kept close at hand so it can be served quickly.
  - *Example:* Clearing the **cache** fixed the outdated prices on the page.

### cookie
- **IPA:** /ˈkʊki/
- **Meaning 1 (n):** A small file a website stores on a user's device to remember information.
  - *Example:* A **cookie** keeps you logged in between visits.

### session
- **IPA:** /ˈseʃn/
- **Meaning 1 (n):** A period of activity between a user logging in and logging out.
  - *Example:* Inactive **sessions** are ended after 20 minutes.

### query

  - *Example:* A slow **query** was making the report page hang.

### index

  - *Example:* Adding an **index** cut the search time from seconds to milliseconds.

### schema

### migration
- **IPA:** /maɪˈɡreɪʃn/

### provisioning
- **IPA:** /prəˈvɪʒənɪŋ/
- **Meaning 1 (n):** The setting up of servers, accounts, or services ready for use.
  - *Example:* Automated **provisioning** spins up a new server in minutes.

### orchestration
- **IPA:** /ˌɔːkɪˈstreɪʃn/

  - *Example:* **Orchestration** software restarts failed services on its own.

### on-premises

  - *Example:* Sensitive records are kept in an **on-premises** system, not the cloud.

### hybrid cloud

### SaaS

  - *Example:* The firm replaced its old install with a **SaaS** product.

### incident response

### help desk ticket

### front-end

### codebase

  - *Example:* The company rents space in a **data centre** on the edge of the city.
