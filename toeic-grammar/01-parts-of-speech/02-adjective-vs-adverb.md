# 02 — Adjective vs. Adverb

> **TOEIC parts:** Part 5, Part 6 · **Priority:** ★★★★★

## 1. The rule

- An **adjective** describes a **noun**: *a **careful** review*. It also follows **linking verbs**
  (*be, become, seem, appear, remain, stay, look, sound, feel, prove, turn*).
- An **adverb** describes a **verb, adjective, other adverb, or the whole sentence**:
  *review **carefully***, ***highly** qualified*, ***very** quickly*, ***Fortunately**, …*

| Pattern | Correct |
|---|---|
| verb + object + ___ | *She handled the complaint **professionally**.* |
| be + ___ + V-ed (passive) | *The room is **fully** booked.* |
| have + ___ + V-ed | *Sales have **steadily** increased.* |
| linking verb + ___ | *The proposal sounds **reasonable**.* |
| make/keep/find + object + ___ | *Keep the area **clean**. / We found the seminar **useful**.* |

## 2. Adverbs TOEIC tests over and over

- **Degree:** highly (recommended/qualified/skilled), extremely, considerably, significantly, slightly
- **Time/frequency:** recently, currently, previously, shortly (= soon), promptly, regularly, frequently
- **Manner:** carefully, efficiently, thoroughly, accordingly, separately
- **Focus/limit:** only, just, solely, exclusively, approximately, nearly, almost

## 3. Look-alike pairs (different meanings)

| Word | Meaning | Example |
|---|---|---|
| **hard** (adv) / **hardly** | with effort / almost not | *works **hard*** / ***hardly** any complaints* |
| **late** / **lately** | not on time / recently | *arrived **late*** / *has been busy **lately*** |
| **high** / **highly** | at a height / very much | *flew **high*** / ***highly** recommended* |
| **near** / **nearly** | close to / almost | *lives **near** the office* / ***nearly** finished* |
| **short** / **shortly** | not long / soon | *ran **short** of paper* / *will arrive **shortly*** |

## 4. TOEIC-style question

> All new employees are expected to complete the training program -------.
> (A) prompt  (B) promptly  (C) promptness  (D) prompted

<details><summary>Answer</summary>

**(B) promptly.** The sentence is already complete (*complete + the training program*), so the blank describes how they *complete* it → **adverb**.
Tip: **if the sentence is already complete without the blank, the answer is almost always an adverb.**
</details>

## 5. Practice

1. The hotel staff were ------- helpful during our stay.
   (A) except (B) exception (C) exceptional (D) exceptionally
2. The board considered the offer -------.
   (A) serious (B) seriously (C) seriousness (D) more serious
3. Customers have found the new interface very -------.
   (A) convenience (B) conveniently (C) convenient (D) conveniences

<details><summary>Answers</summary>

1. **(D)**: an adverb modifies the adjective *helpful*.
2. **(B)**: the sentence is complete, and the adverb modifies *considered*.
3. **(C)**: *find + object + adjective*.
</details>
