# 02 — Quantifiers & Determiners

> **TOEIC parts:** Part 5 · **Priority:** ★★★★

## 1. Which nouns go with which word?

| Quantifier | + singular countable | + plural countable | + uncountable |
|---|:-:|:-:|:-:|
| **each, every, another, either, neither** | ✓ | | |
| **many, few, a few, several, a number of, both, various, numerous** | | ✓ | |
| **much, little, a little, a great deal of, an amount of** | | | ✓ |
| **all, most, some, any, more, a lot of, plenty of, no** | | ✓ | ✓ |

- ***Every** employee **has** a parking space.* (singular noun + singular verb)
- ***Several** applicants were interviewed.*
- ***Much** effort went into the project.*

## 2. few / a few, little / a little

- **a few / a little** = some (positive): *We have **a few** seats left.*
- **few / little** = almost none (negative): ***Few** people attended.*

## 3. "of" patterns

**most / some / many / all / each / none + of + the/my/these + noun**
*most employees* ✓ · ***most of the** employees* ✓ · ~~most of employees~~ ✗
***Each of the** rooms **has** Wi-Fi.* (singular verb)

## 4. another / other / the other / others

| Form | Use | Example |
|---|---|---|
| **another** + singular noun | one more | *Would you like **another** copy?* |
| **other** + plural / uncountable | different ones | ***other** options* |
| **the other** + noun | the remaining one(s) | *One printer works; **the other** one is broken.* |
| **others** (pronoun) | other people/things | *Some prefer email; **others** prefer calls.* |
| **the others** (pronoun) | the rest | |
| **each other / one another** | mutually | *They help **each other**.* |

## 5. TOEIC-style question

> ------- employee is required to complete the online ethics course by March 31.
> (A) All  (B) Every  (C) Many  (D) Most

<details><summary>Answer</summary>

**(B) Every.** *employee* is **singular countable** and the verb is *is*, so **every**. *All / Many / Most* need plural nouns.
</details>

## 6. Practice

1. The hotel offers ------- amenities, including a pool and a spa.
   (A) much (B) every (C) numerous (D) a little
2. Very ------- information about the merger has been released.
   (A) few (B) little (C) many (D) a few
3. If this time doesn't suit you, we can schedule ------- appointment.
   (A) other (B) others (C) another (D) the others

<details><summary>Answers</summary>

1. **(C)**: plural countable *amenities*.
2. **(B)**: uncountable *information* and a negative meaning.
3. **(C)**: one more, singular noun.
</details>
