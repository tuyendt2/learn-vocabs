# 03 — Paired (Correlative) Conjunctions & Parallel Structure

> **TOEIC parts:** Part 5 · **Priority:** ★★★★ (an easy point if you memorize the pairs)

## 1. Fixed pairs: see one half, choose the other

| Pair | Example |
|---|---|
| **both** A **and** B | *The job requires **both** experience **and** creativity.* |
| **either** A **or** B | *You can pay **either** by card **or** in cash.* |
| **neither** A **nor** B | ***Neither** the manager **nor** her assistant was available.* |
| **not only** A **but (also)** B | *The hotel is **not only** affordable **but also** convenient.* |
| **whether** A **or** B (**or not**) | *We'll go **whether** it rains **or** not.* |
| A **as well as** B | *She speaks French **as well as** German.* |
| **between** A **and** B | ***between** 9 A.M. **and** 5 P.M.* |
| **from** A **to** B | |
| **so** + adj **that** / **such** + (a) noun **that** | *The demand was **so** high **that**… / It was **such** a success **that**…* |

## 2. Parallel structure: A and B must have the same form

- *The role involves **writing** reports, **analyzing** data, and **meeting** clients.*
- ❌ *The training was informative and ~~enjoyment~~.* → ✓ *informative and **enjoyable**.*

## 3. TOEIC-style question

> Applicants must submit ------- a cover letter and a copy of their résumé.
> (A) either  (B) both  (C) neither  (D) not only

<details><summary>Answer</summary>

**(B) both.** You can see **and** later in the sentence, so choose **both**. *Either* pairs with *or*, and *neither* with *nor*.
</details>

## 4. Practice

1. Payment can be made ------- online or at any branch.
   (A) both (B) either (C) neither (D) whether
2. The new model is not only lighter ------- more powerful.
   (A) and (B) or (C) but also (D) nor
3. The seminar was so popular ------- a second session was added.
   (A) as (B) that (C) than (D) which

<details><summary>Answers</summary>

1. **(B)**: *either … or*.
2. **(C)**: *not only … but also*.
3. **(B)**: *so … that*.
</details>
