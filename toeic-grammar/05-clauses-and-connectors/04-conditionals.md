# 04 — Conditional Sentences (if / unless / provided that)

> **TOEIC parts:** Part 5, Part 6, Part 7 · **Priority:** ★★★★

## 1. Types

| Type | If-clause | Main clause | Use |
|---|---|---|---|
| **0** | present simple | present simple | general truth: *If you heat ice, it melts.* |
| **1** | present simple | **will / can / may + V** or imperative | real future: *If you **order** today, you **will receive** it by Friday.* |
| **2** | past simple (**were**) | **would / could + V** | unreal present: *If we **had** more staff, we **would open** on Sundays.* |
| **3** | past perfect | **would have + V3** | unreal past: *If we **had known**, we **would have called**.* |

## 2. Other condition words

- **unless** = if … not: ***Unless** you **register** by Friday, you can't attend.*
- **provided (that) / providing / as long as / on condition that** = only if
- **in case** = as a precaution: *Bring an umbrella **in case** it rains.*
- **otherwise** (adverb) = if not: *Please reply by noon; **otherwise**, the seat will be released.*

## 3. ⭐ Inversion: "If" is omitted (formal, appears on TOEIC)

| Normal | Inverted |
|---|---|
| If you **should** need help, … | ***Should** you need any help, please call us.* |
| If I **were** you, … | ***Were** I you, …* |
| If we **had** known, … | ***Had** we known, …* |

*"**Should you have** any questions, please do not hesitate to contact us."* is a classic Part 6 email sentence.

## 4. TOEIC-style question

> ------- you have any questions about your order, please contact our customer service team.
> (A) If only  (B) Should  (C) Unless  (D) Would

<details><summary>Answer</summary>

**(B) Should.** Inverted conditional: ***Should** you have* = *If you have*. *Unless* would not make sense here.
</details>

## 5. Practice

1. If the shipment ------- late, we will offer a full refund.
   (A) arrives (B) will arrive (C) arrived (D) arriving
2. If the company had invested earlier, it ------- more profit.
   (A) will make (B) would make (C) would have made (D) made
3. Visitors cannot enter the lab ------- they are accompanied by staff.
   (A) if (B) unless (C) provided (D) whether

<details><summary>Answers</summary>

1. **(A)**: type 1, present in the *if* clause.
2. **(C)**: type 3.
3. **(B)**: *unless* = if not.
</details>
