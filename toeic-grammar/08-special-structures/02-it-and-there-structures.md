# 02 — "It" and "There" Structures

> **TOEIC parts:** Part 5, Part 6 · **Priority:** ★★★

## 1. There + be (something exists)

The verb agrees with the noun **after** it:
*There **is** a problem.* · *There **are** several problems.* · *There **has been** an increase in sales.* · *There **will be** a short break.*

## 2. It as an empty subject

| Pattern | Example |
|---|---|
| **It is + adj + to V** | ***It is** important **to back up** your files.* |
| **It is + adj + that** | ***It is** likely **that** prices will rise.* |
| **It takes + (person) + time + to V** | ***It takes** about two hours **to drive** there.* |
| **It is said / reported / expected that …** | ***It is expected that** the merger will close soon.* |
| **It is + noun + that/who (cleft, emphasis)** | ***It was** Ms. Ford **who** proposed the idea.* |
| **find / make / consider + it + adj + to V** | *The new system **makes it easier to track** orders.* |

## 3. TOEIC-style question

> The new booking system has made ------- easier for customers to change their reservations.
> (A) them  (B) this  (C) it  (D) its

<details><summary>Answer</summary>

**(C) it.** The pattern is *make **it** + adjective + to V*. Here *it* is an empty object that stands for "to change their reservations".
</details>

## 4. Practice

1. There ------- several complaints about the delay.
   (A) has been (B) have been (C) is (D) was
2. ------- is essential that all staff attend the training.
   (A) This (B) There (C) It (D) That

<details><summary>Answers</summary>

1. **(B)**: agrees with *complaints* (plural).
2. **(C)**: *It is + adj + that*.
</details>
