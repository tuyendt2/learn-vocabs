# TOEIC Grammar & Test Knowledge — Target 650–700

The grammar points and test know-how you need for a **650–700** TOEIC Listening & Reading score.
There is one lesson per Markdown file, grouped into folders by topic. Use it alongside the vocabulary sets in
[`../toeic-600/`](../toeic-600/README.md) and [`../toeic-3000/`](../toeic-3000/README.md).

**New here?** Start with [Test format & score target](10-test-parts-and-strategies/01-test-format-and-score-target.md)
(it shows how many questions you can miss and which grammar to study first), then follow the
[8-week study plan](10-test-parts-and-strategies/06-study-plan-8-weeks.md).

## What is in each lesson

1. **The rule**, with tables and the signal words to look for
2. **Examples** written in TOEIC business contexts (offices, orders, travel, HR)
3. **Common traps**: the wrong options test makers like to use
4. **TOEIC-style question**: one question showing how the point is tested
5. **Practice** questions, with answers hidden in a fold-out block (click *Answer*). Try them before you look.
6. **Review Quiz: 20 questions** at the end of every lesson, with an answer key (answer + one-line reason). Use it to check yourself before the exam; aim for **16/20 or more**. Answer letters are shuffled, so you can't guess from position.

> **About the example questions:** real TOEIC questions are copyrighted by ETS and are not reproduced here.
> Each TOEIC-style question is an **original item** that copies a pattern seen again and again on past tests
> (e.g. *possessive + ___ + of → noun*, *look forward to + V-ing*, *be subject to change*, *Should you have any questions…*).
> For real past questions, use the official ETS TOEIC practice books.

Priority stars (★–★★★★★) show how often a point appears and how much it matters for this score band.

## Pre-exam review routine

1. In the last 1–2 weeks, do the **Review Quiz** of every lesson (780 questions in total).
2. Any lesson where you score **below 16/20**: reread the rule and traps sections, then redo the quiz the next day.
3. Finish with the timed mixed quiz in [Part 5 & 6](10-test-parts-and-strategies/04-reading-part-5-and-6.md) and the passages in [Part 7](10-test-parts-and-strategies/05-reading-part-7.md).

## How to use the files

- Open the folder in **VS Code** (or on GitHub) and use **Markdown preview** (`Ctrl+Shift+V`) so tables and fold-out answers display properly.
- Links between lessons are relative: **Ctrl/Cmd + click** to follow them.
- Keep an **error log**: for each wrong practice answer, write down which lesson it belongs to and reread that lesson weekly.
