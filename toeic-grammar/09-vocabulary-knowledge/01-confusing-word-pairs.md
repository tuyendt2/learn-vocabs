## 1. Similar meaning, different grammar

| Words | Difference | Example |
|---|---|---|
| **say / tell / speak / talk** | tell **sb**; say **sth**; speak **to**; talk **about** | *She **told** the team about the change.* |
| **lend / borrow / rent / lease** | lend **to**; borrow **from** | |
| **remind / remember / recall** | remind **sb of / to** | |
| **raise / rise / arise** | raise **sth**; rise = go up; arise = (problem) appear | *Questions may **arise**.* |
| **affect (v) / effect (n)** | | *The strike **affected** deliveries. / It had a big **effect**.* |
| **cost / price / fee / fare / rate / charge** | fee = service; fare = transport; rate = per unit | *bus **fare**, membership **fee**, interest **rate**, delivery **charge*** |
| **customer / client / guest / patron / passenger** | | |
| **job / work / career / occupation** | work is uncountable (activity) | |
| **almost / most / mostly** | almost = nearly (adverb) | ***Almost all** staff…* (not ~~most all~~) |
| **ago / before** | ago = from now; before = from a past point | |
| **beside / besides** | next to / in addition to | |
| **especially / specially** | above all / for a specific purpose | |

## 2. Similar spelling, different meaning

| Words | Meaning |
|---|---|
| **adapt / adopt** | adjust / take on (a policy) |
| **personal / personnel** | private / staff |
| **complement / compliment** | complete / praise |
| **principal / principle** | main / rule |
| **stationary / stationery** | not moving / office paper |
| **considerable / considerate** | large / kind |
| **economic / economical** | of the economy / money-saving |
| **respectful / respective** | polite / each separately |
| **successful / successive** | achieving / consecutive |
| **reliable / reliant** | trustworthy / dependent |
| **comprehensive / comprehensible** | complete / understandable |
| **sensible / sensitive** | reasonable / easily affected (*sensitive information*) |

## 3. TOEIC-style question

> All ------- information, such as salary details, must be stored securely.
> (A) sensible  (B) sensitive  (C) sensory  (D) sensational

<details><summary>Answer</summary>

**(B) sensitive.** *Sensitive information* means confidential or private data. *Sensible* means reasonable.
</details>

## 4. Practice

1. The firm decided to ------- a more flexible working policy.
   (A) adapt (B) adopt (C) adept (D) adopted
2. The train ------- from London to Paris has increased.
   (A) fee (B) fare (C) fine (D) toll
3. Please contact the ------- department about your vacation request.
   (A) personal (B) personnel (C) personality (D) personally

<details><summary>Answers</summary>

1. **(B)**: *adopt* = take up (a policy).
2. **(B)**: *fare* is used for transport.
3. **(B)**: *personnel* = HR / staff.
</details>
