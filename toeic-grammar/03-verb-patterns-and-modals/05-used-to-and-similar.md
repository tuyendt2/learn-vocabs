# 05 — used to / be used to / get used to & Other Look-alike Verb Patterns

> **TOEIC parts:** Part 5 · **Priority:** ★★

## 1. used to

| Pattern | Meaning | Example |
|---|---|---|
| **used to + V** | past habit (not now) | *The company **used to have** an office in Rome.* |
| **be used to + V-ing / noun** | be accustomed | *Our staff **are used to working** under pressure.* |
| **get used to + V-ing** | become accustomed | *You'll soon **get used to using** the new system.* |
| **be used to + V** (passive of *use*) | be utilized for a purpose | *This room **is used to store** files.* |

## 2. Other often-confused verbs

| Verb | Pattern | Example |
|---|---|---|
| **rise** (intransitive) / **raise** (transitive) | rise – rose – risen / raise – raised | *Prices **rose**.* / *They **raised** prices.* |
| **lie** / **lay** | lie – lay – lain (be flat) / lay – laid (put) | *Please **lay** the documents on the desk.* |
| **say / tell** | say (something) / tell **someone** | *She **told us** that…* / *She **said** that…* |
| **speak / talk** | speak **to/with**, talk **about** | |
| **lend / borrow** | lend **to** / borrow **from** | |
| **remind / remember** | remind **someone to do / of** | *Please **remind Mr. Kim to** sign it.* |
| **explain** | explain **something to** someone (not ~~explain me~~) | |

## 3. TOEIC-style question

> The company ------- its prices twice last year due to rising fuel costs.
> (A) rose  (B) raised  (C) risen  (D) arose

<details><summary>Answer</summary>

**(B) raised.** *its prices* is an **object**, so you need the transitive verb **raise**.
</details>

## 4. Practice

1. Ms. Bell is used to ------- presentations to large audiences.
   (A) give (B) giving (C) gave (D) be given
2. Could you ------- me how to use the scanner?
   (A) say (B) tell (C) speak (D) talk

<details><summary>Answers</summary>

1. **(B)**: *be used to + V-ing*.
2. **(B)**: *tell + person*.
</details>
