# 03 — Causative Verbs (have / make / let / get / help)

> **TOEIC parts:** Part 5 · **Priority:** ★★★

## 1. Patterns

| Verb | Active (person does it) | Passive (thing is done) |
|---|---|---|
| **have** | have **someone do** sth: *I'll **have my assistant send** it.* | have **sth done**: *We **had the printer repaired**.* |
| **get** | get **someone to do** sth: *She **got IT to install** it.* | get **sth done**: *Get the contract **signed**.* |
| **make** | make **someone do** sth (force): *The rules **make us wear** badges.* | (be made **to do**: *We were made to wait.*) |
| **let** | let **someone do** sth (allow): ***Let me know** if…* | — |
| **help** | help **someone (to) do**: *This tool **helps users (to) save** time.* | — |

⚠️ After **make / let / have** (active) → **bare infinitive** (no *to*).
⚠️ Similar meaning but **with to**: *allow / permit / enable / cause / force / require* + object + **to V**.

## 2. Perception verbs: see / watch / hear / notice + object + V or V-ing

*I **saw** him **leave** the office.* (whole action) · *I **heard** someone **knocking**.* (in progress)

## 3. TOEIC-style question

> Please let me ------- if you need any additional information.
> (A) know  (B) to know  (C) knowing  (D) known

<details><summary>Answer</summary>

**(A) know.** *Let + object + bare infinitive.* "Let me know" appears very often in Part 6 emails.
</details>

## 4. Practice

1. Mr. Chen had the documents ------- to the client by courier.
   (A) deliver (B) delivered (C) delivering (D) to deliver
2. The new software allows users ------- reports automatically.
   (A) generate (B) generating (C) to generate (D) generated
3. The manager made everyone ------- the safety video.
   (A) watch (B) to watch (C) watching (D) watched

<details><summary>Answers</summary>

1. **(B)**: *have + thing + V3* (passive).
2. **(C)**: *allow + object + to V*.
3. **(A)**: *make + object + bare infinitive*.
</details>
