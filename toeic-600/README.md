# TOEIC Core Vocabulary — 600 Words

A curated set of ~600 high-frequency words for the TOEIC (Listening & Reading) test,
grouped by **topic** rather than alphabetically. Each entry has:

- **IPA** transcription (British RP / General American where they align; both shown when word stress shifts between noun and verb)
- **English meaning** (short definition)
- **Example** sentence(s)
- If a word has several common senses, only the **first 3 meanings** are given, each with its own example.

> This is the 600-word starter set. The full 3000-word list will live in a separate
> `toeic-3000/` folder beside this one.
